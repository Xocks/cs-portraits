# 照片质量审核器

双击项目根目录的“照片质量审核.command”，或在 cs 目录运行 `npm run review:photos`。
打开 http://127.0.0.1:4180/ 。程序仅监听本机地址。

- 1～5：给当前照片评质量分；4～5 分优先用于网站。
- ← / →：上一张、下一张；空格：暂存待定。
- 可以切换完整原图与人像裁切，并对照右侧档案参考头像。
- 人物不符时使用“人物不符”，不要仅用低质量分代替身份标记。
- 默认排除此前已经人工审核的照片；可按战队、年份、选手和评分筛选。
- 评分成功后自动保存并切图；可以关闭“评分后自动下一张”反复比较。
- 进度写入 `cs/research/top20-quality-ratings.json`；刷新、重开浏览器和重新启动程序后均可继续。
- 支持导出 JSON 备份和 CSV 评分表。质量分与正式网站的选手评分互相独立；评分不会自动发布照片。
- 可修改已有评分或清除本张评分；备注需要随评分/待定保存，或在已评分照片上点击“保存备注”。

维护者整合：`node scripts/apply-photo-quality.mjs` 预览筛选统计；加 `--apply` 更新审核白名单，再运行照片处理、目录生成和测试。不会在用户评分时自动修改线上版本。
